# Yearlong keogram viewer

These files make a vertical-only deep-zoom image, for example used for viewing the year-long keograms that [Cees Bassa]([https://mastodon.social/@cgbassa](https://mastodon.social/@cgbassa/115821827638199300)) makes.

A live version of this viewer it at https://astron.nl/~dijkema/keogramtest/
